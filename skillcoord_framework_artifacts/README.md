# SkillCoord-HRC Framework Artifacts

This package turns the idea into implementation-ready and paper-writing-ready artifacts.

Working title: **SkillCoord-HRC: A Skill-Centric Development and Benchmarking Framework for Human–Robot Multi-Agent Coordination**

Core idea: represent humans and robots as heterogeneous agents with typed executable skills. Skills can be executed by learned policies, classical planners, scripted controllers, simulated humans, teleoperation, or real humans. The framework benchmarks planner quality and skill-execution quality under success, failure, recovery, communication, and safety metrics.

Recommended path:
1. Read `planning/00_PROJECT_CHARTER.md`.
2. Give `engineering/03_IMPLEMENTATION_ROADMAP.md` and `prompts/10_CODEX_MASTER_PROMPT.md` to coding AI.
3. Use `paper/08_PAPER_SKELETON.md` and `paper/09_RELATED_WORK_MATRIX.md` for manuscript writing.
4. Use `templates/skill_spec_template.yaml` when adding a new skill.
